| Replica | Actual random seed | State |
|---|---|---|
| [Replica 1](replica-1/README.md) | 101 | Local continuation paused |
| [Replica 2](replica-2/README.md) | 202 | Original parent; local continuation not started |
| [Replica 3](replica-3/README.md) | 303 | Original parent; local continuation not started |
