# Run the GUI here

**Right-click dashboard.py in PyCharm and choose Run**, or use the shared
**6 RoboCup Dashboard** run configuration. No installation or desktop shortcut.

`dashboard.py` opens controls. `visualize.py` opens the saved walker.
`status.py` prints selected weights. `index_videos.py` refreshes the recording library.
`train.py`, `evaluate.py` and `sweep.py` are separate operations, not needed to open the GUI.
`cluster_dashboard.py` is a compatibility alias for the same GUI.

Read [the quick start](../../START_HERE.md). Training is currently paused; opening
the GUI does not resume it. Do not launch training until the user requests resume.
