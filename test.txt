Here’s the path I’d use.

One-time setup

From repo root:

cd /workspace/cse-145-237d-humanoid-teleop/holosoma-main
bash scripts/setup_retargeting.sh
source scripts/source_retargeting_setup.sh
pip install -e src/holosoma_retargeting
Then work from the retargeting package dir:

cd /workspace/cse-145-237d-humanoid-teleop/holosoma-main/src/holosoma_retargeting/holosoma_retargeting
Visualize retargeted LaFAN from /cephfs

For the ch_robot result:

python viser_player.py \
  --robot_urdf models/ch_robot/ch_robot_10dof.urdf \
  --qpos_npz /cephfs/holosoma/data/lafan/retargeted/ch_robot/dance2_subject1.npz \
  --assume_object_in_qpos False \
  --loop True
For the foot-flat variant:

python viser_player.py \
  --robot_urdf models/ch_robot/ch_robot_10dof.urdf \
  --qpos_npz /cephfs/holosoma/data/lafan/retargeted/ch_robot_footflat/dance2_subject1.npz \
  --assume_object_in_qpos False \
  --loop True
viser_player.py will print a local viewer URL, usually something like http://localhost:8080. Open that in a browser.

Compare retargeted vs original

The saved retargeted .npz already includes the preprocessed original human joints as human_joints, but the existing standalone viewer only shows the robot qpos. For quantitative comparison, use the existing evaluator:

python evaluation/eval_retargeting.py \
  --res_dir /cephfs/holosoma/data/lafan/retargeted/ch_robot \
  --data_dir /cephfs/holosoma/data/lafan/processed_npy \
  --data_type robot_only \
  --robot ch_robot \
  --data_format lafan
And for foot-flat:

python evaluation/eval_retargeting.py \
  --res_dir /cephfs/holosoma/data/lafan/retargeted/ch_robot_footflat \
  --data_dir /cephfs/holosoma/data/lafan/processed_npy \
  --data_type robot_only \
  --robot ch_robot \
  --data_format lafan
If you want visual side-by-side original human joints vs retargeted robot, the current script that does that most directly is during retargeting with debug/visualize enabled, not from a saved file:

python examples/robot_retarget.py \
  --robot ch_robot \
  --data_path /cephfs/holosoma/data/lafan/processed_npy \
  --task-type robot_only \
  --task-name dance2_subject1 \
  --data_format lafan \
  --task-config.ground-range -10 10 \
  --save_dir /cephfs/holosoma/data/lafan/retargeted/ch_robot_debug \
  --retargeter.debug \
  --retargeter.visualize \
  --retargeter.foot-sticking-tolerance 0.02
Small gotcha: for robot_only files, pass --assume_object_in_qpos False to viser_player.py; otherwise the viewer may try to interpret the end of the robot qpos as an object pose.
